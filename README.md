# -weather-app

My role. Developed and designed a React-based weather app with RESTful API integration for real-time data.
https://mahwish-inamdar.github.io/-weather-app/
#Project description.

This React-based weather application provides real-time weather updates and a 5-day forecast for any city. The app integrates with the OpenWeatherMap API to fetch accurate data for different locations. By focusing on clean design and responsive development, the app allows users to easily check the current weather conditions. This project enhanced my skills in API integration, React, and front-end development, while creating an interactive and responsive user experience.
